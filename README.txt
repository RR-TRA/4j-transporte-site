4J TRANSPORTE — SITE V2 ORGANIZADO

COMO EDITAR
1. Abra a pasta do site.
2. Abra o arquivo config.js com o VS Code, Notepad++ ou outro editor.
3. Altere apenas os valores dentro de SITE_CONFIG.
4. Salve e abra o index.html no navegador para testar.

O QUE VOCÊ PODE ALTERAR NO config.js
- Nome da empresa
- Slogan
- Base/endereço
- WhatsApp
- E-mail
- Telefone
- Instagram
- Título e descrição do Google
- Texto da página inicial
- Números da frota
- Serviços
- Fotos e legendas da galeria
- Segurança e controle
- Estados/regiões atendidos
- Diferenciais
- Textos das seções

WHATSAPP
Digite somente números, com 55 + DDD + número.
Exemplo: 5591999999999

E-MAIL
Exemplo: comercial@4jtransporte.com.br

FOTOS
Coloque as novas fotos dentro da pasta assets e altere o nome do arquivo no config.js.
Exemplo: assets/caminhao-novo.jpg

IMPORTANTE
- Não renomeie index.html ou config.js.
- Não apague as pastas assets.
- Faça uma cópia do site antes de grandes alterações.
- Para publicar, envie index.html, config.js e a pasta assets para a hospedagem.

ESTRUTURA
/index.html       = página do site
/config.js        = informações que você vai editar
/assets/          = fotos do site
/README.txt       = este manual
