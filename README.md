# 4J Transporte Site

Site institucional criado com HTML, CSS e JavaScript, com base na configuração do arquivo `site-config.js`.

## Como editar

Altere principalmente o arquivo `site-config.js` para atualizar:
- nome da empresa
- slogan
- contatos
- textos de serviços
- frota
- regiões de atuação
- diferenciais

## Como executar localmente

Abra o arquivo `index.html` no navegador, ou rode um servidor local:

```bash
python -m http.server 8000
```

Depois acesse:

```text
http://localhost:8000
```

## Publicação

Você pode publicar facilmente em:
- Vercel
- Netlify
- GitHub Pages

## Observação

Algumas imagens foram substituídas por imagens externas para garantir visualização imediata sem depender de arquivos locais.
